### A little about me

My projects range from student council tools and air quality dashboards to warehouse workflows and Python utilities. I work mainly with **TypeScript, React, and Next.js**, with **Python** for APIs and command-line tools.

I'm also exploring how AI can support learning and software development—from classroom feedback in **WhisperHunt AI** to an AI-assisted warehouse management experiment.
